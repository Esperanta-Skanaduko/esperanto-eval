# Reviewing the answer keys

The answer keys follow standard Esperanto rules and are generated by code, but **no native or fluent speaker has reviewed them yet.** Review is the most useful contribution to this project.

## How

1. Open `data/v0.1/review-sheet.csv` in a spreadsheet. It has one row per item: `id`, `task`, `prompt`, `gold_answer`, and empty columns for your name, a verdict and a comment.
2. For each item, ask: *is the gold answer the only correct answer to the prompt?* Sort or filter by `task` to review one kind at a time. A good first pass is `word-building` (72 rows) and `correlative-write` (45 rows).
3. Mark the verdict:
   - **ok**: correct, and no other answer would be right.
   - **wrong**: the gold answer is incorrect.
   - **ambiguous**: another answer is also acceptable (for example, a second common spelling or a synonym), or the prompt can be read two ways.
4. Send the sheet back as a pull request that adds your file under `reviews/`, or open an issue using the "Answer key problem" form for a single item.

## What happens with your review

- **wrong** items are fixed in the generator or the curated list, and the benchmark version number goes up (`v0.2`), because changing items changes scores.
- **ambiguous** items get an `alternatives` list, or are removed.
- The version history records the reviewers' names (with permission) and how many items each one checked.

## Notes for reviewers

- The sentences are deliberately plain and sometimes odd ("The man sees the big tree"). Only grammar is being tested.
- Word-building prompts name a root, an affix and a meaning; the gold answer is the standard derivation, and a prompt is "ambiguous" if a different regular formation has that meaning.
- Number words follow PMEG: tens and hundreds are one word (`dudek`, `ducent`), thousands are separate (`du mil`). The scorer ignores spaces in word answers.
