# Method

## What is measured

Eight tasks, 577 items in `v0.1`. Every item is a question with one correct answer that follows from a published rule of Esperanto grammar. Nothing is graded on style or fluency.

| Task | Items | Question | Scored as |
| --- | ---: | --- | --- |
| `correlative-write` | 45 | Write the correlative that means "somewhere", "always", "no one's"... (all 45 words of the table, once each) | exact word |
| `correlative-meaning` | 60 | What does `tiam` mean? Four options: the right one, one that shares the prefix, one that shares the suffix, one random | letter |
| `accusative` | 100 | Add `-n` / `-jn` to the object and its adjective in a sentence given with no accusative, in SVO or OVS order, with an English sentence to say who does what; subjects and nouns after a preposition must stay unmarked | exact sentence |
| `grammaticality` | 100 | Which of two sentences is correct? Five kinds of single error, 20 each: noun-adjective agreement, predicate agreement, missing accusative, accusative after `estas`, accusative for a static location. A and B are the answer equally often | letter |
| `word-building` | 72 | Combine a root and an affix into the standard derived word (`lerni` + `-ejo` = `lernejo`) | exact word |
| `conjugation` | 100 | Give a tense, the conditional, the imperative or one of the six participles of a regular verb. Passive participles are asked only of transitive verbs | exact word |
| `number-write` | 50 | Write 0-9999 in Esperanto words | words, spaces ignored |
| `number-read` | 50 | Write an Esperanto number word as digits | digits |

The overall score is the **average of the eight task accuracies**, so a big task does not drown a small one. Every task accuracy is reported with a 95% Wilson interval; with 45 to 100 items per task, differences of a few points between two models are noise.

## Where the answer keys come from

- **Correlatives, accusative, agreement, conjugation, numerals** are generated by code from the rules of the language, from small vocabularies of regular words. The correlative table is the one in the Fundamento; the English glosses of its 45 words are written for this benchmark. Other rules follow the Fundamento and the [Plena Manlibro de Esperanta Gramatiko](https://bertilow.com/pmeg/) (PMEG), whose conventions for number words (hundreds and tens are one word, thousands are a separate word) the numeral tasks use.
- **Word-building** uses a curated list of 72 textbook formations (see `src/tasks/wordBuildingData.mjs`), each a regular, settled word.
- **The code is the audit trail.** The `generate` command rebuilds the shipped items from the seed in `data/v0.1/manifest.json`, and `verify` checks the result byte for byte against the SHA-256 there. Independent tests check the keys with code that does not share logic with the generators (for example, every number from 0 to 9999 is converted to words and read back by a separately written reader).

**What has not been done: no item has been reviewed by a native or fluent speaker.** The rules are standard, but vocabulary choices, glosses and a few word-building meanings could still hold a mistake. See [REVIEW.md](REVIEW.md) for how to review and send corrections; `data/v0.1/review-sheet.csv` lists every item.

## How replies are scored

Every model is held to the same strict rules, and the raw reply is always saved so scoring can be redone (`esperanto-eval rescore`).

- **Prompt.** Each item's prompt is sent as one user message, temperature 0, a short token limit (default 256). No system prompt, no examples, no chain-of-thought request.
- **Choice items.** A reply is read as a letter if it begins with the letter (`B`, `B) ...`, `**B**`), says "Answer: B", says "the correct sentence is B)", or mentions exactly one option marker such as `B)`. A reply that names two different options, or none, is wrong.
- **Number items.** The first run of digits; spaces, dots and commas inside it are removed.
- **Text and word items.** The text after "Answer:" if present, otherwise the first non-empty line.
- **Comparison.** Unicode NFC, lower case, x-system spellings (`cxu`) read as real letters, surrounding quotes and trailing punctuation removed, spaces collapsed. Word items additionally ignore spaces and hyphens, so `dumil` equals `du mil`.
- **Failures.** A failed request counts as wrong and is recorded with its error.

## Limits

- **It measures rule application, not fluency, vocabulary or translation.** A model can score well here and still write unnatural Esperanto. Translation quality is a different question; see [Open Machine Translation for Esperanto](https://arxiv.org/abs/2603.29345) (de Gibert and de Gibert, 2026), which evaluates open translation systems for Esperanto.
- **Templated sentences are simple.** Real texts are harder. Passing these items is necessary, not sufficient.
- **A frozen set leaks.** Once `v0.1` is published it can end up in training data. `esperanto-eval generate --seed N` makes fresh items from the same rules; compare scores on both.
- **The vocabulary is small** (about 30 nouns, 8 adjectives, 24 verbs), so item variety comes from structure, not words.
- **One prompt per item, no repetition.** Results depend on the wording of the prompts; they are kept in the data so you can see them.
- **The first run is one small model.** See the README table. Treat any single row as a data point, not a ranking.
